# NFL Bets

Read-only GitHub Pages export of the local NFL Bets dashboard. Publish from main, root directory. No build dependencies.

This repository must contain only the reviewed static export. Never copy .env.local, the SQLite database, account entries, raw provider responses, or backup directories into it.

Data timestamps are displayed in the interface. Reloading does not run the local model or fetch sportsbook odds. Updating the website requires exporting and pushing a new snapshot.
