How the model works

Historical player production and opportunities inform a statistical distribution. The deployed probability combines model and market information. The selected book price determines single-bet expected return.

The 5%+ EV view keeps the best eligible offer per player, game and prop category. It is a current-snapshot screen; the frozen trial separately records first eligible admissions before kickoff.

The comparison view uses 20% model / 80% market and a 5-percentage-point edge. A 5-point probability edge is different from 5% expected return.

Expected return is not guaranteed profit. Related player props are correlated. Pick6 and PrizePicks entry returns require their exact lines, payout rules and joint outcomes; these sportsbook calculations do not provide entry EV.

Data collection and model computation run on the private local installation. This GitHub Pages build contains only an exported public snapshot. Account entries, API credentials and the local database are not published.
